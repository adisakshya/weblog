## 3. Mockups in Lovable (Step B)

- Copy the 3 posts' public Markdown and front matter, `_data` (navigation and comments), and the referenced images into `mockup-content/` as read-only snapshots, with the source commit SHA recorded. The prose is not edited.
- A small build-time loader parses front matter, tags, series order (Introduction, then Setup), reading time (Minimal Mistakes' 200 words per minute) and kramdown-compatible heading IDs, so anchors match production.

### Routes
- **Original paths:** `/weblog/`, `/weblog/2022/07/16/setting-up-an-api-ateway-for-your-microservices.html` (and the other two posts), `/weblog/tags/<tag>/` for all 9 tags, `/weblog/series/api-gateway-101/`, `/weblog/contact/` and `/weblog/terms/`.

If the preview server can't serve a path ending in `.html` directly, the mockup uses a stated alias and the original stays in the route map. The imported hashed routes stay untouched as the visual baseline until you approve the design.

### Screens and interactions (all working, not static)
1. **Header:** Agustina masthead "The blog of Adisakshya Chauhan", Writing, About me (`https://adisakshya.github.io/`), Search with a "/" hint, and a preferences menu. Compact at 320 px.
2. **Landing page:** the original intro line with optional emoji, Stories as the default, an Index toggle (state kept on return), and proposed Systems and Developer tools groupings that link to the original tag URLs. A compact API Gateway 101 section.
3. **Covers:** 3 accurate SVG diagram or typography covers, with fixed text colours on each cover and alt text.
4. **Article:** centred column of 60–65 characters, a collapsed "On this page" section inside the column, code copy with feedback, scrollable code and tables, image enlargement, series position with previous and next links, related writing, the existing comments shown read-only, and the comment form as it is now with its status noted.
5. **Series, tag, contact and terms pages** in the new design.
6. **Search dialog:** empty, results and no-results states. The index is built from the Markdown snapshot in the same shape `lunr-store.js` produces, so the handoff matches. Keyboard and focus behaviour follows Rednafi.
7. **Preferences:** 8 themes, serif or sans, and 3 text sizes. Saved locally, applied before the page is painted, follows System mode, and falls back safely when storage is unavailable.
